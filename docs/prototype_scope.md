# Prototype Scope – RoomLight

## Goal

The goal of this prototype is to show how the basic idea of RoomLight works in practice. It focuses on the core functionality of controlling and synchronizing lighting between multiple rooms.

## What is included

- Ability to create and store multiple rooms
- Basic light settings (on/off, brightness)
- Simple lighting modes (for example night mode and energy saving mode)
- One main lighting setup (master configuration)
- Apply the main setup to all rooms at once
- Ability to view the current lighting status of each room

## What is not included

- Real lights or hardware integration
- Network communication between devices
- Login or user accounts
- Advanced user interface (only simple or basic view)
- Detailed energy tracking or analytics

## Limitations

- The system will run locally and does not connect to real devices
- Changes are applied manually, no automatic sensors
- The focus is on logic, not performance or scalability

## Notes

This prototype is meant to test the main idea and structure of the system. It helps to understand how rooms, lightning settings and synchronization work before building a more complete version.

The main goal is not to build a full product, but to create a simple working model of the system.
